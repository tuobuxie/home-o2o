# 前端环境配置文件说明

## 📁 环境文件列表

项目中有 4 个环境配置文件：

### 1. `.env.development` - 开发环境配置
**用途**：开发环境（`npm run dev`）的默认配置
**内容**：
```bash
VITE_API_BASE_URL=http://localhost:3001/api
```
**说明**：开发时默认使用本地后端服务

### 2. `.env.local` - 本地覆盖配置 ⭐ 优先级最高
**用途**：本地特定配置，会覆盖其他环境文件
**特点**：
- 优先级最高，所有环境都会加载
- 通常包含个人开发配置
- **不会被提交到 git**（已在 .gitignore 中排除）

**当前内容**：
```bash
# 可以在这里添加个人本地配置，例如：
# VITE_API_BASE_URL=http://192.168.1.100:3001/api
```

### 3. `.env.local.example` - 本地配置示例
**用途**：作为 `.env.local` 的模板文件
**说明**：新成员可以复制此文件创建自己的 `.env.local`

### 4. `.env.production` - 生产环境配置
**用途**：生产环境（`npm run build`）的配置
**内容**：
```bash
VITE_API_BASE_URL=http://8.159.141.134:3001/api
```

## 🔄 Vite 环境文件加载机制

Vite 按照以下**优先级从高到低**加载环境变量：

```
1. .env.local                    ← 最高优先级（本地覆盖）
2. .env.[mode].local             ← 模式特定的本地配置
3. .env.[mode]                   ← 模式配置（development/production）
4. .env                          ← 默认配置（最低优先级）
```

### 实际加载情况

#### 开发环境（`npm run dev`）
```
加载顺序：
1. .env.development
2. .env.local (覆盖 .env.development 中的相同变量)

最终使用的配置：
- VITE_API_BASE_URL: 如果 .env.local 中有，使用 .env.local 的值
                     否则使用 .env.development 的值
```

#### 生产环境（`npm run build`）
```
加载顺序：
1. .env.production
2. .env.local (覆盖 .env.production 中的相同变量)

最终使用的配置：
- VITE_API_BASE_URL: 如果 .env.local 中有，使用 .env.local 的值
                     否则使用 .env.production 的值
```

   - `.env.development` 之前指向远程服务器，应该指向本地

3. **缺少验证**：
   - 没有验证必需的环境变量是否存在

## ✅ 优化建议

### 1. 统一环境变量管理
- `.env.development`: 开发环境默认配置（本地后端）
- `.env.production`: 生产环境配置（远程服务器）
- `.env.local`: 个人本地覆盖配置（不提交到 git）

### 2. 添加类型定义
已在 `src/env.d.ts` 中添加环境变量类型定义

### 3. 添加环境变量验证
已在 `services/apiService.ts` 中添加开发环境警告

### 4. 使用建议
- 团队共享的配置放在 `.env.development` 或 `.env.production`
- 个人特定配置放在 `.env.local`（不会被提交到 git）
- 新成员复制 `.env.local.example` 创建自己的 `.env.local`

## 📝 如何修改配置

### 修改开发环境配置
编辑 `.env.development` 文件

### 修改生产环境配置
编辑 `.env.production` 文件

### 添加个人本地配置
1. 复制 `.env.local.example` 为 `.env.local`
2. 在 `.env.local` 中添加或修改配置
3. `.env.local` 中的配置会覆盖其他环境文件

### 示例：使用不同的后端地址
在 `.env.local` 中添加：
```bash
VITE_API_BASE_URL=http://192.168.1.100:3001/api
```
这样开发时会使用这个地址，而不是 `.env.development` 中的默认值。
